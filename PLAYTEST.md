# Playtest notes

What to try first, and where people usually get stuck.

## Fast path (one person)

1. Open the app, pick a piece (or skip — Start hands out a leftover), tap **Join**. Join stays hittable; no name opens a prompt that fills the field and then joins. That sit name is who **Stats** tracks (Dad and dad are the same). **Learning — don’t write to Stats** starts **off**; opening **How to play** turns it **on**. Toggle anytime in lobby/table; locked at Start. Learning seats show **· learning** and do not write the board. One of each token, like Monopoly (Cat and Tiger are both in the box); taken pieces are greyed. First visit: **New to 3-13?** with **How to play** or **I know this** (does not block Join). How to play asks for a name when empty. Replay from lobby **How to play** (header, next to Stats) or the book icon on the table. Optional coach tips on hands 1–5; **Stop coach** / **Skip tutorial** anytime. Gold **Stats** sits next to Copy link and jumps down past join/start to the Stats card. Tap a seated human name to look them up. On a phone, Add to Home Screen should offer 3-13.
2. As host, tap **Add bot** under the names list if you want extra seats (solo Start already adds one). Guests do not see Add bot.
3. You’re the host (first to join). Gold **Join** and **Start** sit together. Alone (no other human, no bot) **Start game** auto-adds one bot and toasts **Added a bot so you can play**, then deals. A friend or any bot already seated → no auto-add. **Pick first dealer** (optional). Deadwood aces default to **Aces score 15**; tap **Aces score 1** if you want the old 1-point house. **Caught wilds = face value** starts **on** (rank-wilds use printed face; **jokers score 0**) — uncheck it before Start for wilds 15 / jokers 20. **Idle auto-move** is **off** unless you check it (3 min / 180s force-play). **Wager rules** is **off** unless you check it (play-money $5 chips; losers pay the winner). House rules lock at start. A second seated player cannot start — the button says so.
4. A full-screen toast should say **Round 1 — 3s are wild**. Dismiss it or wait; the gold banner on the table stays. Each later round announces its own wild (4s, then 5s, … Kings).
5. Drag cards in your hand to rearrange (works on a phone). **Melds** groups legal runs and 3+ sets (same ace/wild rules as the table); Rank / Suit / Wilds first are still there. Order is local — it will not jump back when the table syncs. You can drag after any sort. The top strip shows **previous / current / next** around the table (wraps at 2 players). Other hands stay face-down. Layout uses `data-device` on `<html>` (phone if the short screen side is under 600px; tablet if that side is 600+ and the device has touch / a coarse pointer — including iPad “desktop site”; otherwise desktop). **Tablet** (portrait and landscape): top row is felt **stock/discard** on the left and the **scoreboard** on the right; your hand + Melds/Rank/Suit/Wilds first sit full-width underneath (piles stay clipped in TABLE). Desktop is felt | hand with running scores under both. After a hand, the **full scoreboard** is the main scroll area — it is not clipped by the 100dvh frame. Portrait phones stay one column with face-down fans.
6. On your turn, tap the stock or the face-up discard, then tap a card and **Discard**.
7. If the rest of your hand is all sets/runs, **Go out** lights up. Yellow outline = wild this round.

A two-bot table will also finish a round by itself if you sit, add bots, start, and watch.

## Two phones / two browsers

1. Host copies the **link** (`?room=WORD-NN`), not just the homepage.
2. Guest opens the link and taps **Join** (name prompt if the field is empty). Same room code should show in the header.
3. If the guest landed on a different code, they pasted the origin without `?room=` — use **Join code**.
4. Open **Talk**. Both browsers should see the same messages with names and times. Tags like `<b>` should show as plain text. **Chat overlay while playing** starts **on** for new browsers (two lines under previous/current/next). Uncheck it in Accessibility or Talk to hide the strip. A saved off stays off. **Join Discord voice** opens the invite in a new tab. Local mic is this device only.
5. Room codes are `WORD-NN` (example **KITE-7**). **`?room=PLAY-A` stays on that bad code** — error copy names KITE-7, Join/Start stay locked, and the tab does **not** jump to a different room like MOSS-63. Type a valid code or tap **New code**.

No accounts. Identity is a browser `localStorage` id plus a saved room session, so the same phone reconnects to the same seat after a refresh, Wi‑Fi blip, or sleep. You should see **Reconnecting…** then **You're back**. If the server restarted, the copy says the table was wiped — sit again; do not expect the old hand.

## Known friction

- **This is not Liverpool.** You do not lay melds on the table during the hand. You hold everything until someone goes out.
- **You must draw, then discard**, even if you already had a going-out hand. After you draw: **Tap a card to select, then Discard**. The selected card lifts and says SELECTED. Tap it again to **deselect**. Throw it with the Discard button (or optional double-tap / long-press if those are on). **Go out** only appears when a legal go-out discard exists; those cards are marked GO OUT. If someone takes the upcard, a faint **scooped** outline of that card sits beside the pile until they throw a new discard.
- **Go out needs a discard.** After drawing you have one extra card; that extra card is the discard. The other cards must all meld.
- **All-wild piles are illegal** here. A 3-3-3 when 3s are wild is not a meld.
- **Last turns:** after someone goes out, everyone else still gets one draw/discard **in the same seating order** (the next seat after the person who went out, then around). The round is not over on the go-out card.
- **Host vs guest:** the host can add bots (under the names list) or roll the dealer. **Only the host (first to join) can start.** Guests do not see Start or Add bot.
- **2s and Aces are never wild.** Wild is only the rank equal to the deal (3s … Kings). Face marks, coach tips, and leftover scoring follow that — never treat rank 1 or 2 as the wild even if something passed it in.
- **Aces high or low in runs** (`A-2-3` and `Q-K-A`; no `K-A-2` wrap). Sets of aces are fine. Deadwood ace **points** are a separate lobby toggle (15 default or 1). **Caught wilds = face value** is a separate scoring-only toggle (**on** by default = printed rank, jokers 0; off = wilds 15 / jokers 20).
- **Any discard that leaves a fully melded hand goes out automatically.** The table flashes **“{Name} went out!”** on every screen, then last turns / scores continue.
- **Idle auto-move is optional** (lobby checkbox, **off** by default, locked at Start). **Off:** the table names whose turn it is and waits — no countdown, no force-play. **On:** humans get a 3 minute (180s) countdown (`3:00`); a stall auto-plays a legal move and an **Auto-move** toast appears. A dropped connection uses 4s. Reconnects do not restart the clock. Separate: the **host** can check **Auto-play** next to a human name so the bot takes that seat until they rejoin or the host unchecks it.
- **Stock empty:** the table shuffles the discard except the face-up card into a new stock. If only that upcard is left, draw from discard (stock draw is blocked). If both piles are empty, the round scores current deadwood.
- **Bots keep wilds.** They will not discard the round wild (or a joker) unless every card in hand is wild.
- **“2 rounds on 4” is the rules, not a scoring bug.** Round 2 deals **4 cards** and **4s are wild**. Four seated players use **two** 52-card decks (104). After a go-out the scoreboard holds **12s** before the next deal so it does not feel like the round vanished.
- **The public “crash” was the Fly process dying, not a deal exception.** Dual machines each had their own in-memory rooms (split-brain / empty lobby), and `auto_stop_machines` sent SIGINT (exit 130) which wiped tables. There was no JS stack in the Fly logs. The app now stays up (`auto_stop` off, one machine) and a bad turn is caught so it cannot kill the process.
- **Rooms are in memory.** Restarting `npm run dev` (or the process) wipes every table and score. A reconnect to the same code after a wipe shows **Server restarted or this table was wiped** — it is not a silent empty lobby. If the process stayed up, the same phone/browser id + saved room code reclaim the same seat and hand. A drop shows **Reconnecting…**; a successful claim shows **You're back**.
- **Support hosting** on the lobby opens Stripe Checkout in a new tab (helps cover Fly). No cards are typed in this app.
- **Accessibility** lives in the lobby card (and the accessibility icon on the table chrome) and stays on this browser. New browsers start with **Bigger ranks & suits**, **Mark wilds on cards**, **Sound on your turn**, and **Chat overlay while playing** on; a saved `tt-a11y` blob is not overwritten, and a blob without `markWilds` stays on. Uncheck **Mark wilds on cards** to hide the yellow ring and WILD badge (play rules do not change). Mid-hand is fine. The overlay puts two lines under previous/current/next. Talk still works either way. **Double-tap** (400ms) and **long-press** (550ms, no drag) are extra discard paths.
- Later rounds (10–13 cards) take longer. The bot is greedy, not brilliant; it will dump points and go out when it can.
- **Hand order is yours only.** Dragging cards does not tell the server anything. A tap still selects for discard; a short slide rearranges. If a sync “resets” your hand, that is a bug — reload should keep the same order for the current round.
- **Chat is best-effort.** A server restart wipes the transcript with the room. Voice chat lives on Discord for now. The two-line top bar appears when **Chat overlay while playing** is on (the default for new browsers).
- **Wager rules are play money.** Check the lobby box before Start, then pick $1 / $5 / $10 / $20 or a custom start (locks at Start). The table shows the current stake. After the match, 🏆 and “X owes Y $10” are the settlement — no real money. A first-place tie with wager on is sudden death from deal 3, not a shared win. End game mid-match clears scores and does not settle.
- **Stats open on the global board.** Gold **Stats** jumps to the lower card (the old Rounds slot) and shows every sit-name: W–L, 🥹, 😭, stars, sweep glow. Tap a row (or a seated human name) for that person’s card; **Back** returns to the list — do not get stuck. Hall of Fame / Hall of Shame always show the all-time best and worst with who and the date; a personal tip-forget does not remove those lines. Personal **Forget this for a tip 😅** still clears that card only. Learning seats (the Stats toggle, default off; How to play turns it on) do not write a row — same as bots — locked at Start. Gold glow only after first-out on all 11 regulation hands. SQLite on the Fly volume (`/data/sit-stats.sqlite`) survives redeploys.

## What “good” looks like

- Round 1 deals 3 cards, 3s wild, one deck for 2–3 players.
- Four seated players get two 52-card decks (104).
- After a go-out, a **scoreboard** fills the table: this-round points, running totals, who went out, deadwood, and a per-round card. Next deal waits **12s** (or tap **Next round**). Then **round 2 deals 4 cards with 4s wild**.
- Lowest running total is winning; going out scores 0 that round. Match end ranks everyone and offers **Back to lobby** (anyone seated; same room and seats). If **Wager rules** was on, the winner shows 🏆 and each loser’s play-money owe (stake × one multiplier). Mid-hand the **host** has a gold **End game** button in the top-right chrome (next to Talk / Accessibility). Guests see a disabled **Host can end game**. Confirm: “End game and return to lobby?” That is not the same as **Leave room**. **Leave room** is always in the table chrome (and in the lobby when you are seated): one tap stands you up, hands host to the next human if you were host, and lands you on a fresh create-or-join lobby. Others keep playing if two seats remain. Voice chat says **Leave voice**, not Leave. A forced end does not settle chips.
- **Wager is fake chips.** No payments, no banks. Sit-name **Stats** open on a global board (W–L, 🥹, 😭, stars) with immortal Hall of Fame / Shame; **Back** returns from a person’s card.
